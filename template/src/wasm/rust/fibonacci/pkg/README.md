# Rust WebAssembly Example

This directory contains a Rust crate that compiles to WebAssembly using `wasm-pack` and `wasm-bindgen`.

## What It Does

The `src/lib.rs` file exports a single function:

```rust
#[wasm_bindgen]
pub fn fib(n: i32) -> i32
```

Which computes the nth Fibonacci number iteratively.

## Pre-built Artifacts

The `pkg/` directory contains pre-built output from `wasm-pack`:

- `fibonacci.js` — JavaScript bindings generated by wasm-bindgen
- `fibonacci_bg.wasm` — Compiled WebAssembly binary
- `fibonacci.d.ts` — TypeScript type definitions

You can import the module directly in your JavaScript:

```javascript
import init, { fib } from './wasm/rust/fibonacci/pkg/fibonacci.js';

await init();
console.log(fib(10)); // 55
```

## Rebuilding from Source

### Prerequisites

Install wasm-pack:

```bash
curl https://rustwasm.github.io/wasm-pack/installer/init.sh -sSf | sh
```

Or on macOS with Homebrew:

```bash
brew install wasm-pack
```

### Build

From the project root:

```bash
npm run build:wasm:rust
```

Or from this directory:

```bash
wasm-pack build --target web
```

The `--target web` flag generates ES module output suitable for direct browser import without a bundler.

## Cargo.toml Notes

- `crate-type = ["cdylib"]` — Required for wasm-pack to produce a dynamic library
- `wasm-bindgen` — Generates JS bindings for Rust functions
- `opt-level = "z"` and `lto = true` — Optimize for smallest binary size
